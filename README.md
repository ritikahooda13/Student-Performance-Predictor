# Student Performance Predictor System 🎓

## 📝 Project Description
This project is an AI-based Machine Learning system designed to predict a student's final academic marks. By analyzing key personal and academic indicators—such as daily study hours, class attendance, previous exam scores, and assignments performance—the model provides highly accurate predictions to help educators and students evaluate performance early.

---

## 📌 Features
* **Machine Learning Model:** Random Forest Regressor with 86.92% accuracy (R2 Score).
* **Interactive Dashboard:** Built using Streamlit for live user-input predictions.
* **Dynamic Feedback:** Provides instant insights and performance warnings based on predicted grades.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Frontend/UI:** Streamlit

---

## 📊 Dataset Features Included
* Study Hours (Daily)
* Attendance (%)
* Previous Exam Score (Out of 100)
* Assignments Score (Out of 100)
* **Target Variable:** Final Marks
